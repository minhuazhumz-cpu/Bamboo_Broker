# Bamboo Broker

A playful web-based sales forecasting game for a sales team. All characters are pandas selling bamboo through four seasonal turns: Spring, Summer, Autumn, and Winter.

## Run locally

```bash
npm install
npm run dev
```

## Game loop

1. Review 3 seasonal Bamboo Deals with value and close probability.
2. Submit a forecast to the Elder Panda by flagging risk and/or opportunity.
3. Close the season and watch the deals roll.
4. Receive Elder Panda feedback, trust-meter movement, and continue toward the yearly Bamboo Stalk target.
